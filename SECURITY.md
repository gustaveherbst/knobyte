# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.9.x   | :white_check_mark: |
| < 0.9   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Knobyte, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email **gustave.herbst** (refer to GitHub profile for email) with:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested fixes (optional)

## What to Expect

- **Acknowledgment** within 48 hours of your report
- **Status update** within 7 days with an assessment and next steps
- **Fix timeline** depends on severity — critical issues will be prioritized

## Scope

This policy applies to the `knobyte` binary, MCP server, and Hub. Third-party dependencies are outside the scope of this policy, but we appreciate being notified if you find issues in our dependency chain.

Thank you for helping keep Knobyte secure.
